Entry for the [Worst Fix Ever: Funniest Commit Message](https://make.fun/bounty/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722) competition on make.fun: one commit message, at most 100 characters, for a bug fix that made everything worse.

A Python program (standard library only, deterministic, no network) that writes one commit-message line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` or `/output`).

The line:

> fix: login now works for everyone, with any password, including 'password'

## Layout

- `main.py` — entrypoint run by the grader.
